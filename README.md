# Pong

A simple Pong-copy that I made to better understand Godot

<br>

## Controls

### Left Paddle (Blue)

* **W**
  - Move Up
* **S**
  - Move Down

### Right Paddle (Red)
Optionally can be set to a "robot".

* **Up Arrow**
  - Move Up
* **Down Arrow**
  - Move Down
